# Third Lever Games

A small static landing page for Third Lever Games. No build step or dependencies required. Open `index.html` in a browser.

## Publish for free with GitHub Pages

1. Create a new GitHub repository called `third-lever-games`.
2. Upload the files in this folder to the root of the repository.
3. Go to **Settings → Pages**, select **Deploy from a branch**, branch **main**, folder **/(root)**, and save.
4. Your site will appear at `https://YOUR-USERNAME.github.io/third-lever-games/`.

You can change any text directly in `index.html`. The logo is an editable SVG in `logo.svg`, also used for `favicon.svg`. The font is loaded from Google Fonts, falling back to built-in system fonts when offline.
